# 中日 偽友詞（False Friends）・認知のズレ図鑑

> 汉字相同、字面看似一致——但底层**认知坐标系**不同的词。
> 不是「手紙＝厕纸」式的词汇表事故，而是「軸・領域・極性・レジスター」层面的深层错位。

- 线上：**https://syu-toutousai.github.io/false-friends/**（手写单文件，离线可用）
- 收录 **19 组**深层伪友词，按六类分组：

| 组 | 词条 | 认知机制 |
|---|---|---|
| A 社会と役割 | 立場・遠慮・我慢・迷惑 | 道徳軸→社会役割軸、時間軸→対人軸、自我膨張→抑制、内→外 |
| B 目標と公私 | 対象・質問・用意 | 親密圏⇄客観目標（相手と対象の分割）、対抗→中性、内意図→外準備 |
| C 評価と極性 | 真面目・得意・検討 | 褒貶反転、語槽の分割、倫理軸→実務軸 |
| D 身体と比喩 | 皮肉・邪魔・工夫 | 身体/宗教語の日常化、量→質 |
| E 動作と能力 | 上手／下手・勉強 | 動作の起点→能力評価、三段漂移（勉強→学習→譲歩） |
| F 社会のトポロジー | 人間・世間・都合・適当 | 空間（世界）→存在（人）、天地→評価共同体、主観の客体化、レジスター二重人格 |

## 各词条结构

1. **中文核心义／日语核心义**（并排）
2. **认知漂移**——哪根轴被换掉了
3. **误用剧场**——真实会翻车的对话（❌/⭕）
4. **认知解读**——为什么会这样漂移
5. **N1 真题命中**——从合并题库 `jlpt-question-bank` 的 `n1/` 子树抽取，
   仅展示**回次・問題・题号元数据**与加密站深链，**不转载真题原文**；
   另有按年份的分布条

## 维护

- `index.html` 手写维护（无构建）；新增词条 = 加一张 `.pair` 卡 + 补小测题。
- 真题命中数据 `HITS` 由本地题库扫描生成后注入（词条 → N1 题目 id 列表）；
  修改词表后重新扫描即可，只写元数据、不写题干。
- 引用与版权：真题目录 id 只是「哪年哪回哪题」的坐标；真题原文遵循题库加密政策
  （<https://syu-toutousai.github.io/jlpt-question-bank/>，密码解锁）。
- 判定流仪：语义漂移是**解释**，与语源一样要贴标签（諸説あり・共用层 vs 日常层），
  不要用单一故事盖住全部用法。
